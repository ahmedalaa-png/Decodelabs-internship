# Project 3: SQL Data Analysis

## Description
This project uses SQL queries to extract business insights from the e-commerce dataset using Python and SQLite.

## Files
- ecommerce_sql.csv - Input dataset
- project_3_sql_analysis.ipynb - SQL analysis notebook
- sql_revenue_by_product.png - Revenue chart
- sql_monthly_trend.png - Monthly trend chart

## SQL Queries Used
- SELECT with filtering
- WHERE clause
- GROUP BY with COUNT, SUM, AVG
- HAVING clause
- ORDER BY

## How to Run
pip install pandas matplotlib seaborn
jupyter notebook project_3_sql_analysis.ipynb

## Tools Used
Python, Pandas, SQLite3, Matplotlib, Seaborn
